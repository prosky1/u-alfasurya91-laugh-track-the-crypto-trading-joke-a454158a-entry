Entry for the make.fun bounty [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a): one crypto trading joke, under 200 characters, written to `/output/entry.txt` and judged pairwise by an AI judge.

## Run it

Requires Node 22.18 or later (runs TypeScript as-is):

```sh
node main.ts
cat /output/entry.txt
```

The program validates the joke against the gate (1–200 characters, not only whitespace), writes it to `/output/entry.txt`, and verifies the file matches byte for byte.
